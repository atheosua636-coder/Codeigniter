# Simple POS System

A four-page Point-of-Sale foundation built with CodeIgniter 4.

## Pages

- Home
- About
- Customer Accounts
- User Accounts

Customer and user records are stored in static PHP arrays. This version does
not use a database.

## Local Installation

1. Clone the repository.
2. Run `composer install`.
3. Copy `env` and rename the copy to `.env`.
4. Configure `app.baseURL` in `.env`.
5. Open the application through the `public` directory.

## Routes

- `/`
- `/about`
- `/customers`
- `/users`
